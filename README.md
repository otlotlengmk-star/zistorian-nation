# The Man Behind Zistorian Nation

Independent tribute website celebrating Siyabonga Emmanuel Nkosi. Not an official betting platform.

## Publish on GitHub Pages
Upload `index.html` and the `images` folder to the repository root. In Settings > Pages choose Deploy from a branch, `main`, `/ (root)`.

## Privacy
The two photographs featuring a newborn have been excluded. Confirm permission from pictured individuals before publishing.
